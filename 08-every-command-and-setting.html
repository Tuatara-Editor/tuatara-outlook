Every command and setting

Each command and setting of outlook, to look one up by name.

The tables are made from the program each time this manual is made, so they never list a command or setting that outlook does not have. The first table has four columns. The first two are keys: the modal keys, which work only with modal editing on, and the non-modal keys, which work with it off too. A command with no key says M-x and its name in the second column, because you can only run it by its name. The third column is the name of the command and the fourth says what it does.

To run a command by its name, press M-x, type a few letters of the name and press RET. To find a command from within the editor, press C-h f. To find the command that a key runs, press C-h k and then the key. The editor's own settings and commands are in chapters 21 and 22 of its manual.

8.1 Every command

ModalNon-modalCommandWhat it does
noneh, C-c o houtlook-back-to-directoryClose the list of the mailbox, after asking, and list its directory with rimu, point on the mailbox: the messages written of it stay in the cache, as when it is closed any other way, until unused for CACHE-KEEP.
noneC, C-c o coutlook-exportOpen the menu of copying the messages marked in the mailbox's list, or with none marked the one on the current line, out: e as saved mail (.eml) and m as Outlook items (.msg) into a directory, b into one mbox file, p into a new Outlook mailbox (.pst), the directory or the file asked for then.
noneM-x outlook-export-emloutlook-export-emlCopy the messages marked in the mailbox's list (m), or with none marked the one on the current line, out into a directory asked for, as saved mail (.eml).
noneM-x outlook-export-mboxoutlook-export-mboxCollect the messages marked in the mailbox's list (m), or with none marked the one on the current line, into one mbox file asked for, the format most mail programs read: each message as it was written, after a From line, a line of it beginning with From (after any number of >) written with one > more, as mboxrd does.
noneM-x outlook-export-msgoutlook-export-msgCopy the messages marked in the mailbox's list (m), or with none marked the one on the current line, out into a directory asked for, as Outlook items (.msg), as M-x outlook-export-eml copies them as saved mail.
noneM-x outlook-export-pstoutlook-export-pstWrite the messages marked in the mailbox's list (m), or with none marked the one on the current line, into a new Outlook mailbox (.pst) asked for, in the folders they are listed in: each with every property, recipient and attachment the Outlook item written of it holds, its named properties among them.
noneL, C-c o loutlook-filter-labelsNarrow the mailbox's list to the messages carrying a label, or any of several, chosen apart by commas from those its messages carry (+); with C-u, to those carrying none of them.
none+, C-c o +outlook-labelPut labels on the messages marked in the mailbox's list (m), or with none marked on the one on the current line: several, apart by commas, the labels used before offered and new ones typed.
noneM, C-c o moutlook-label-managerList the labels kept for mailboxes (M-x outlook-label), a section for each mailbox with the labels on its messages, to rename, delete, forget, copy out and read back; the heading says where they are kept and how much room they take.
nonel, C-f, REToutlook-label-openOpen the mailbox of the section the current line is in, as it was last opened, when its file is there; otherwise say why not.
noneR, C-c o routlook-label-renameRename the label on the current line, or each label marked, asking for the new name of each: on every message of its mailbox that carries it.
noneE, C-c o eoutlook-labels-exportWrite the labels of the mailbox the current line is in into a file, in the directory and under the name asked for (the mailbox's name and .labels at first): a plain text file holding the mailbox's SHA-256 sum, its file's name and, for each message, its identity and its labels, to be read back by I.
noneD, C-c o foutlook-labels-forgetForget every label of the mailbox the current line is in, after saying how many labels and messages that is: its journal is deleted, and the mailbox starts without labels the next time it is opened.
noneI, C-c o ioutlook-labels-importRead a file of a mailbox's labels, written by E, and add them to the mailbox whose SHA-256 sum it holds: those it has already stay, and none is taken away.
noneO, C-c o ooutlook-open-attachment-outsideOpen the attachment at point in the desktop's own program for its kind, after asking: a copy of it only you can read, never the message, and only an attachment of a kind that may be opened outside Tuatara (a picture, a PDF, a sound, a video, an Office document, by its contents, with a name that agrees; see open-externally-kinds).
none-, C-c o -outlook-unlabelTake labels off the messages marked in the mailbox's list, or with none marked off the one on the current line: several, apart by commas, chosen from those they carry (+).
noneT, C-c o toutlook-view-file-textShow the file of the message shown as its text, the file itself: opened safely when the message was (one of a mailbox, an attachment), else as any file is opened, as text.
noneP, C-c o poutlook-view-pagesShow the message shown as it looks, as pages: its HTML laid out as a screen shows it, drawn by outlook-page-program (WeasyPrint) shut in the sandbox, the pictures it holds in their places.
